## 固定モデル・条件

- q = softmax(log(正規化逆オッズ市場参照) + w・x)。単なる温度補正や凸混合ではない。
- 19特徴：元予測/市場参照のlog比を±5でclipし5で割った1列、1〜3着の艇番one-hot各6列。判断時点の保存済み予測・オッズ・組番のみ。未取得の選手・モーター特徴は作らない。
- レース平均multiclass NLL + 0.1/2 × ||w||²。ゼロ初期値、学習率0.2、600反復を固定。ハイパーパラメータ探索なし。
- 学習対象は10月14〜17日の証跡・結果検証通過行のみ。10月13日は既存のユーザー指定除外を維持。閲覧済み入力の全race IDを評価除外集合に残す。
- 元のprobStdはそのまま保守的risk proxyに使用。変換後の校正済み不確実性とは主張しない。
- 両比較群に同一制約：確率0.10以上、オッズ50以下、月間購入総額10,000円以内、レース上限1,000円。払戻の再投資なし。未確定券と月跨ぎ未確定持越しも既存replayで予約する。部分期間開始前の未提供保有は復元できず、完全月の証明・月間黒字頻度は算出しない。

## 未見評価の手順

1. 有効な保存済み入力を供給し、`node scripts/market-residual.mjs freeze INPUT ARTIFACT` で学習。新規artifactだけを書き込み、実際の作成時刻、実装hash、入力hash、係数、学習/閲覧済みrace IDを固定する。
2. artifactのSHA256を別途保持してから、新しい結果入力を用意する。今回のprotocol記録は**未学習**であり、これを学習済みartifactと混同しない。
3. `node scripts/market-residual.mjs evaluate INPUT ARTIFACT REPORT EXPECTED_ARTIFACT_SHA256`。実装・artifact hash、出典モデル・protocolを検証した後だけ入力を読む。
4. artifact作成より**後に判断された**レースだけを受付。学習・既閲覧raceとの重複、過去期間、証跡不足は全体を拒否する。これは過去の閲覧有無を自己申告するより厳しい将来限定の経路。評価用の結果がない場合は成績を作らず、公式検証済み結果のみproper scoreに使用する。購入選択・risk予約には結果不明レースも含める。

SHAはファイル同一性の証跡であり、第三者署名・生データ再検証の代替ではない。候補係数が固定される前の結果を未見と呼ばず、結果比較後の再学習は新しい候補・新しい将来期間を必要とする。
