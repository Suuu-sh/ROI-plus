# Sample seed

`sample.sql` is generated by `generate.mjs` using a fixed LCG seed. It is intentionally anchored to the generator's current JST calendar day so it always contains today's scheduled cards and 60 prior days of completed fixtures. Recreate it with:

```sh
node db/seed/generate.mjs
```

The generated file is checked in with the database migration. Every generated domain record is `data_origin='sample'`; all names are visibly marked as sample data and do not represent actual races, odds, predictions, outcomes, or purchases. Regenerate it when the calendar advances if today's-card examples are needed.
